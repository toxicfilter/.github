<h3 align="center">Content moderation API</h3>

<p align="center">
  Allow, review or block, with the reason in words and the fragment that triggered it.<br>
  About a millisecond for most comments. <a href="https://toxicfilter.com">toxicfilter.com</a>
</p>

---

Send what your users write (comments, profiles, listings, images, conversations) and get back a decision you can act on. Fifteen categories instead of one toxicity score, rules per site, and a model that only reads what the free detectors leave open.

## SDKs

| Language | Install | Repository |
|---|---|---|
| PHP | `composer require edulazaro/toxicfilter-sdk` | [php-sdk](https://github.com/toxicfilter/php-sdk) |
| Python | `pip install toxicfilter-sdk` | [python-sdk](https://github.com/toxicfilter/python-sdk) |
| JavaScript | `npm install toxicfilter-sdk` | [js-sdk](https://github.com/toxicfilter/js-sdk) |
| Laravel | `composer require edulazaro/laratox` | [laratox](https://github.com/edulazaro/laratox) |
